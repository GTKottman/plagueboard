# Plagueboard

Source of https://plagueboard.com: the Irkutsk plague rumor tracker (timeline, the leak, follow the money,
red string board). `site/` is a static page deployed by Coolify (static build pack, base directory `/site`) on the
Mortiflix Hetzner server. The working copy lives in Morti Drive at `Design Docs/Irkutsk Plague Timeline/`;
copy `index.html` + `assets/` here and push to `main` to redeploy.
